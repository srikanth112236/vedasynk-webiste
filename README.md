# Vedasynk Technologies Website

Premium, SEO-first marketing site for Vedasynk Technologies (Bangalore).

## Stack

- Next.js (App Router) · React · TypeScript · Tailwind CSS
- Framer Motion · GSAP ScrollTrigger · Lenis
- MDX blog · React Hook Form · Zod

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

## Key routes

- `/` Homepage
- `/services`, `/services/[slug]` (16 services)
- `/solutions`, `/solutions/[slug]`
- `/industries`, `/industries/[slug]`
- `/portfolio`, `/case-studies`, `/blog`
- `/about`, `/process`, `/technology`, `/careers`, `/contact`
